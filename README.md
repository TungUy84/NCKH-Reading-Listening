# 🧠 Hệ Thống Luyện Thi Nghe – Đọc Tiếng Anh

Đây là một nền tảng web giúp học sinh luyện tập các kỹ năng **Nghe và Đọc tiếng Anh**, có khả năng cá nhân hóa lộ trình học theo trình độ hiện tại của người dùng. Hệ thống được xây dựng bằng **ReactJS (frontend)**, **Node.js + Express (backend)** và **MongoDB (database)**.

## 🚀 Tính Năng Chính

- ✅ Đăng ký / Đăng nhập bằng Email (JWT Authentication)
- 🎯 Làm **bài kiểm tra đầu vào (Placement Test)** để xác định trình độ (AV1–AV7)
- 🗺️ Gợi ý **lộ trình ôn tập cá nhân hóa**
- 📚 **Làm bài luyện tập** với các dạng bài Nghe – Đọc phong phú
- 📝 **Thi thử (Mock Test)** mô phỏng bài thi thật
- ✅ Hệ thống **tự chấm điểm**, đưa ra **giải thích đáp án**
- 📅 **Lập lịch học**, gửi **nhắc nhở qua email**
- 📰 **Blog học tập**, mẹo làm bài, chia sẻ kinh nghiệm

⚙️ Công Nghệ Sử Dụng
Frontend: ReactJS, React Router

Backend: Node.js, Express, JWT, Mongoose

Database: MongoDB (self-hosted hoặc MongoDB Atlas)

Authentication: JSON Web Token (JWT)
